# BM25 검색기 평가 질문 세트 작성 가이드

## 목적

BM25 검색기의 성능을 빠뜨림 없이 평가하려면 질문 개수만 늘리는 것이 아니라,
`정보 단위 × 질문 표현 × 난이도`를 기준으로 평가 범위를 관리해야 한다. 기존
20문항은 기본 동작 확인용으로 사용하고, 본격 평가는 60~80문항 규모로 확장한다.

## 1. 검색 가능한 정보 단위 목록화

청크당 질문 하나를 만드는 대신, 대본에서 실제로 질문하고 답할 수 있는 정보를
먼저 분리한다. 하나의 청크에 여러 정보가 있을 수 있고, 인사나 잡담처럼 질문할
필요가 없는 청크도 있기 때문이다.

| 정보 ID | 정보 내용 | 근거 청크 예시 |
|---|---|---|
| F01 | 열용량의 정의 | chunk 18, 19 |
| F02 | B보다 D의 열용량이 큰 이유 | chunk 19 |
| F03 | 113번에서 주위 온도가 낮아지는 이유 | chunk 13, 14 |
| F04 | 모르는 문제를 표시하는 방법 | chunk 2 |

모든 정보 단위가 평가 문항에 최소 한 번 이상 포함되어야 한다.

## 2. 동일 정보의 질문 변형

정보 하나마다 다음과 같이 최소 세 가지 표현을 만든다.

- 직접 질문: `열용량의 정의가 뭐야?`
- 바꿔 말하기: `물질 온도를 1도 높이는 데 필요한 열은 뭐라고 해?`
- 불완전한 학생 표현: `온도 올릴 때 필요한 에너지 그거 뭐였지?`
- 표기·띄어쓰기 변형: `열 용량이 뭐야?`
- 문맥형 질문: `B와 D 중에서 왜 D가 더 큰 거야?`

정확한 화학 용어가 포함된 질문만 사용하면 BM25 성능이 실제보다 높게 측정될 수
있으므로, 바꿔 말하기와 불완전한 표현을 반드시 포함한다.

## 3. 문항 필드와 역할

```json
{
  "id": "Q021",
  "category": "개념 설명",
  "question_type": "바꿔 말하기",
  "difficulty": "중",
  "variant_group_id": "F01",
  "question": "물질 온도를 1도 올리는 데 필요한 에너지를 뭐라고 해?",
  "relevant_chunk_ids": [
    "2026-08-19_audio_transcript_science_class:chunk:0018",
    "2026-08-19_audio_transcript_science_class:chunk:0019"
  ],
  "target_keywords": ["열용량", "1℃", "열량"],
  "gold_answer": "물질의 온도를 1℃ 높이는 데 필요한 열량을 열용량이라고 합니다."
}
```

- `question`: BM25에 실제 입력하는 학생 질문
- `relevant_chunk_ids`: 4단계 검색 정답 판정에 사용
- `target_keywords`: 토큰화와 어휘 근거 진단에만 사용
- `gold_answer`: 5단계 LLM 답변 평가에만 사용
- `variant_group_id`: 동일 정보를 다르게 질문한 문항 묶음

`gold_answer`와 `target_keywords`를 BM25 검색어나 순위 계산에 사용하면 안 된다.

## 4. 필수 질문 유형

- 개념 정의와 원인 설명
- 비교와 그래프 해석
- 문제 번호 기반 질문
- 숙제·퀴즈·수업 일정 등 수업 운영 질문
- 교사 또는 학생 발화에 관한 질문
- 한두 단어로 된 짧은 질문
- 앞 문맥이 생략된 질문
- 조사·띄어쓰기·오타가 있는 질문
- 학생이 부정확한 용어로 표현한 질문
- 비슷한 화학 개념을 섞은 어려운 질문
- 답이 여러 청크에 걸친 질문
- 대본에 답이 없는 질문

현재 4단계 평가기는 빈 `relevant_chunk_ids`를 허용하지 않으므로, 대본에 답이 없는
질문은 별도의 `bm25_no_answer_eval.json`으로 관리하거나 평가기를 확장한다.

## 5. 권장 문항 구성

첫 번째 본격 평가 세트는 60~80문항을 권장한다.

| 구성 | 권장 문항 수 |
|---|---:|
| 직접 질문 | 20 |
| 바꿔 말하기 | 20 |
| 띄어쓰기·오타·불완전 표현 | 10 |
| 유사 내용이 있는 어려운 질문 | 10 |
| 여러 청크가 정답인 질문 | 5 |
| 대본에 답이 없는 질문 | 5 |

질문 유형은 서로 겹칠 수 있으므로 각 문항에 복수의 특성을 태깅할 수 있다.

## 6. 정답 청크 지정 원칙

- BM25 검색 결과를 확인하기 전에 정답 청크를 지정한다.
- 실제 답을 직접 뒷받침하는 청크만 정답으로 지정한다.
- 청크 중복이나 경계 때문에 설명이 여러 청크에 걸치면 모두 정답으로 지정한다.
- 주제가 비슷할 뿐 답을 포함하지 않는 청크는 정답으로 지정하지 않는다.
- 가능하면 두 사람이 독립적으로 정답을 지정한 뒤 불일치를 조정한다.

## 7. 핵심 성능 기준

- 전체 Hit@5: 95% 이상
- 전체 Recall@5: 95% 이상
- MRR@5: 0.85 이상
- 질문 유형별 Hit@5: 90% 이상
- 바꿔 말하기 질문 안정성: 90% 이상
- 검색 지연시간 p95 확인
- 특정 유형이 전체 평균보다 10%p 이상 낮으면 병목으로 판정

수업이 여러 개 쌓이면 질문을 무작위로 나누지 않고 수업 단위로 개발 세트와 최종
테스트 세트를 분리한다. 같은 수업으로 검색기를 조정하고 다시 그 수업으로 평가하면
성능이 과대평가될 수 있다.
